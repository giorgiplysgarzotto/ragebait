# Ragebait

A 16-player, single-elimination debate tournament for parties. Players are paired off, each pair gets a random debate prompt, and a judge picks who won. Winners advance through the bracket until one champion is left.

I built it as a gift for my sister's graduation, and wrote all of the code myself.

> **Content note:** the prompts are intentionally provocative. They mention real public figures and include adult language. It's a party game for adults who know each other.

## How a game works

1. **Set up the bracket.** Enter player names, two at a time, to fill the 16 slots.
2. **Play a match.** Each match shows a random debate prompt.
   - Player One argues for 60 seconds.
   - Player Two rebuts for 60 seconds.
   - The judge (the person running the game) decides who won.
3. **Advance.** Winners move on through the quarterfinals, semifinals, and finals to a champion.

Prompts are generated by combining templates (`app/cardpatterns.tsx`) with lists of subjects, issues, events, places, and objects (`app/carddata.tsx`). Edit those lists to change what comes up.

## Tech

- [React Router](https://reactrouter.com/) 7 and React 19
- TypeScript
- Tailwind CSS 4 (via the Vite plugin)
- Vite
- Docker (multi-stage build)

## Run it locally

Requires Node 20 or later.

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173`.

Other scripts:

```bash
npm run build       # production build
npm run start       # serve the production build
npm run typecheck   # generate route types and run tsc
```

### With Docker

```bash
docker build -t ragebait .
docker run -p 3000:3000 ragebait
```

Then open `http://localhost:3000`.

## Project layout

```
app/
  routes/home/game/
    Game.tsx          # owns all tournament state (bracket, rounds, champion)
    bracket-ui.tsx    # bracket view
    round-ui.tsx      # a single match: prompt, timers, judging
  routes/home/enter.tsx   # name entry and round-advance controls
  components/         # prompt card and small UI pieces
  cardpatterns.tsx    # prompt templates
  carddata.tsx        # subjects, issues, events, places, objects
```

## Known limitations

- Game state lives only in React state, so refreshing the page resets the tournament.
- The bracket is fixed at 16 players.
- There are no automated tests.
